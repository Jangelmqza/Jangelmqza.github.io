Arquitectura del Proyecto

Esta aplicación interactiva guía el despliegue de un servidor NAS seguro en una Raspberry Pi 3B. El objetivo es crear un sistema eficiente que permita gestión local (SMB) y acceso remoto seguro (SFTP) evadiendo restricciones de ISP mediante UPnP y DDNS.
